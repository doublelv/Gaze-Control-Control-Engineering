# firmware/Core/Src

Generated by STM32CubeMX (not committed until the pins are final). Handwritten logic stays in `../../App/`.

Add exactly these lines to the generated `main.c`, inside the USER CODE sections
(CubeMX keeps them when it regenerates):

```c
/* USER CODE BEGIN Includes */
#include "app.h"
#include "bsp/bsp_stm32h7.h"
/* USER CODE END Includes */

/* USER CODE BEGIN 2 */          // after all MX_..._Init() calls
bsp_start();
app_init();
/* USER CODE END 2 */

/* USER CODE BEGIN 3 */          // inside while (1)
app_poll();
/* USER CODE END 3 */
```

The UART receive callback lives in `App/bsp/bsp_stm32h7.c` (`HAL_UART_RxCpltCallback`).
Do not define it again in `main.c`.
